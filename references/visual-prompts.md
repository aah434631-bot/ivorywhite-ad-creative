# B版图片资产与独立逐镜视频提示词

完整创作任务在A版导演方案后读取。本文件规定B版的复制格式。B版成片总时长必须与A版一致：默认短片≤30秒，用户要求长片时按该长片总长；完整方案至少16镜，可增加。B版不重复A版的创意解释、摄影说明或完整导演分镜，只把需要生成的内容整理成独立提示词。图片资产是增强项，不是开始制作的门槛。用户明确只要其中一路时精简另一条的说明，不改变已选创意和镜头时间线。

后续创意轮次在用户尚未选定方案前不读取本文件，不输出B版；用户选定方案后再按同一时间线生成B版。

## 1. 两条使用路径

**路径A：直接生成。** 上传产品白底图，复制某镜的完整视频提示词；无需先生成模特、场景或道具图。这里是参考图加文字的视频生成，不混称纯文生视频。镜头没有产品时明确“本镜不出现产品，产品参考图不构成出镜要求”，避免每镜强塞产品。

**路径B：资产辅助。** 先按下述顺序选定模特、场景和必要道具图，再把有关资产连同产品参考和同一份视频提示词交给工具。资产图只作身份／环境参考，不是逐镜首帧。

不承诺一张产品图可在所有工具中完成任意开场或全片。工具若只能以输入图作为固定起始画面，或不支持多图／角色参考，简短说明这一路径的限制，不假装参考图与首帧等同。默认仍给工具无关指令，不把核实工具能力变成概念创作的前置问卷。

**不提供关键画面、关键帧、首帧、尾帧或逐镜故事板图片提示词，不以其他名称恢复该模块；也不要求先把产品、模特和场景合成镜头图。** 用户以后明确要求这些额外交付时再处理。若工具当前不适合约定流程，说明限制，不擅自加回已排除的步骤。

## 2. 图片提示词：每条独立复制

图片提示词与导演设定分开，不能只把“见人物档案”当成提示词。每张图片单独一块，带清楚标题和完整提示词正文。实际输出使用界面支持的可复制区块；不要把解释性文字混进生成正文。模型未指定时不虚构图号、参数或上传状态。

### 模特：先全身定妆，再面部妆发

有模特的完整方案分别提供两条图片提示词；无模特时写“不需要模特资产”，不强加人物。

1. **全身定妆图**：成人年龄感、脸型、五官、肤色、身形、发型发色、妆容、全部衣物的款式／颜色／面料观感、鞋履、配饰、指甲、自然姿态；完整头脚、无遮挡、简洁中性背景、柔和中性光，清楚呈现造型。不要提前把模特塞进广告场景或要求她手持产品。
2. **面部与妆发近景**：重述关键身份特征、发型、妆容、耳饰和衣领等实际出镜细节；正面或轻微侧面、真实肤质、清晰五官、无夸张磨皮。说明“使用已选定的全身定妆图作为同一人物参考”，不是独立随机生另一个人。

图片生成顺序：先选定全身图，再依据它生成同一人的近景。如果工具不支持人物参考，不保证两图同一身份；可建议复用已选定图，不宣称能凭文字完全锁脸。多模特逐人建立，保持各自身份区分。

### 场景：先主要空间，再必要的同空间角度

每个主要场景给独立空景提示词：地点／环境类型、尺度、建筑结构、主要材质、平面布局、入口出口、固定道具数量和摆位、前中后景、时间／天气、光源方向、色彩和明暗。

默认无模特、无产品，预留未来人物活动和产品放置区域；固定道具可以出现。不要为建场景而生成错误品牌产品。

先选定主要空间全貌图。确实需要同一空间另一角度时，使用已选全貌作为环境参考，保持布局、窗户、光源和道具位置，不当作新的随机场景。不是逐镜生成场景图，也不为每个镜号建图。

### 关键道具：只在需要时单独建资产

仅为造型特殊、反复出现或明显影响跨镜连续性的道具提供独立提示词，写外观、数量、比例、颜色、材质观感和清晰展示方式。普通桌椅等已在场景中清楚固定的物件无需再拆成大量资产任务。

P1产品始终以用户原图为外观依据，不强迫重新生成白底图或用生成仿制图覆盖原图。精确Logo和文字后期使用获授权素材校正，不自动删除原有标识。

## 3. B版视频提示词：每镜一份，兼容两条路径

B版视频提示词与A版使用完全相同的镜号、时间码和镜头功能。B版每条独立可复制，不要求用户另找共同前缀；但不再重新解释A版的创意，不复制A版的声音／剪辑段落，也不写一套第二导演脚本。

与导演脚本使用完全相同的镜号、片中时间码和时长，默认短片≤30秒，长片按指定总长且分段生成，至少16镜；不能另给8镜缩略版，镜头数量可按A版增加。**每镜完整、自足，复制这一条即可，不要求用户另找共同视觉前缀再拼接。** 摄影、色调、关键外观与状态按本镜需要直接写入，不把全片所有资产重复灌入每一镜。

每镜组织：

镜头NN｜片中起止时间｜目标时长｜叙事镜头／产品展示镜头／视觉事件镜头
- 直接生成：附产品白底图；若本镜无产品，明确不出镜。所有镜头共用的使用说明可只写一次。
- 可选参考：列出资产辅助路线实际需要附的已选定图片；不虚构工具图号或已上传状态，不包含镜头首帧图。
- 可复制提示词：只放本镜可生成的视觉正文，独立成块；声音和剪辑说明留在A版或BGM区。

### 按当前景别精简，而非重复全档案

用“固定身份锚点＋当前画面可见细节＋本镜动作”组织。保留独立生成必需的描述，但不把每条写成完整定妆档案。

- 鞋部镜头写裤脚、鞋、地面、光影与步伐，不写眼睛、唇妆或画外手表。
- 面部或佩戴近景写脸、发型、妆容、实际可见衣领／饰品和产品，不重复鞋履。
- 手部镜头写袖口、左右手、可见饰品、接触与物品状态，不重复脸型和身高。
- 产品静物只写产品、展示环境、构图、摄影与动作，不夹带模特档案。

这些是按画面筛选信息的例子，不是新的固定镜头类型；产品必要外观、身份、空间和动作承接不能因精简被删掉。每镜只写当前可见身份与状态，不复制全片档案或完整导演段落。

正文写清：
- 简短写摄影机／镜头成像参考、焦段、画幅和本镜必要的影调；沿用本片设定，不每镜换系统，不附厂商链接、来源脚注或器材评测。
- 实际出镜的人物关键身份、妆发、服装配饰；产品可见外观与原图约束；只描述当前出镜对象。
- 具体环境、布局关系、主光和色彩，不能只写S1／M1／“同上”。
- 景别、机位、构图、焦点、固定或镜头运动。
- 起始状态、时长内可完成的动作、结束状态；哪只手持物、瓶盖等状态以及必要前镜承接信息用具体文字重述，不依赖“接上一镜”四个字。
- 本镜需要的排除项；不要在每镜复制一长串无关禁词。

视觉正文不写“本镜为了表现高级感”等创意解释，也不塞剪辑论文、BGM发展、采购、上传或来源说明。A版已写过的导演解释不在B版重复；B版只保留当前镜头的可见主体、环境、构图、动作、状态和必要排除项。无人物时不让人物档案自动生成一个人；固定镜头或稳定光线都允许。

声音来自A版导演脚本的逐镜音效及独立BGM提示词；B版视觉正文不默认加入声音，明确支持联合音频控制的工具可再按其真实格式加音频字段，不默认禁止BGM。

### 长片B版分组

沿用A版分段表，每组先写“段落N｜全片时间范围｜计划生成长度｜镜号范围”，以及最必要的可选参考与跨段起止状态；每镜标题保留全片时间码，可附局部时间范围方便在生成工具中使用。不要每组重新从镜头01编号。每组生成长度≤30秒，有已知更短工具上限时取更短值。

所有镜头仍分别给自足提示词，不用“前一段同上”代替外观、场景或持物状态；段末和下段开头要连贯。工具只支持单镜时进一步按镜执行，分组仍用于剪辑组织，不声称工具原生支持整组控制。

延长片子时，完整更新视频提示词、全片BGM提示词和分组，不只改第一行“60秒”。画面分段不把BGM分成彼此重启的独立曲目。不要恢复关键画面／首帧图片模块。

## 4. 连续性与制作边界

先区分连续叙事镜头与明确的独立展示／非叙事插镜；B版提示词保留A版的镜头功能标签。叙事内部维护并检查：本镜开始状态 → 动作 → 结束状态 → 下一镜承接。检查持物左右手、物品位置与数量、瓶盖／开合、服装配饰、人物朝向／路线、入口窗户、光源方向和道具摆位。允许有意跳切或换场，但必须在脚本和对应提示词中清楚交代，不靠用户自行修补。

独立展示镜头的提示词直接描述该展示环境与产品状态，不为接到它而虚构人物搬运、放回或反复取戴。独立展示是剪辑中的明确切换，不是剧情物品瞬移的借口。

导演分镜和视频提示词须表达同一动作与状态，不额外输出庞大连续性表。镜面里的倒影与实体数量分清，不把合法反射误算为额外产品，也不无故多生复制品。

优先原图支持的产品角度，不安排未知背面／内部探索、拆机或无依据的结构动作。场景奇观不暗示未经确认的真实功效。

按镜生成再剪辑是默认可执行组织方式，成片总时长不等于工具单次长度。匹配切、字幕、落版、配乐、精确调速与混音留在后期，不声称模型一次准确执行16镜以上和全部时间码。字数限制通过拆镜／拆批解决，不删减已承诺内容。
