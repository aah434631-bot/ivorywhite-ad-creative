# 广告风险初筛清单

此清单用于识别需要修订或进一步核实的风险，不是任何地区的完整法律规则，也不替代专业审核。不要把所有地区或平台的要求混为一谈。

## 确认适用条件

尽可能确认投放国家／地区、平台、产品类别、目标年龄段和素材形式。缺失时说明初筛范围及未覆盖的地区／平台政策。

针对具体法律、广告禁限用语、必须披露内容、广告标识、促销规则或平台准入要求的判断，应查询当前有效的监管机构、法律原文或平台官方政策，并说明适用范围、查询日期和依据。无法访问或信息不足时，明确待审，不杜撰条款、罚则或过审结论。

## 检查文本与画面

| 检查项 | 需要关注的情况 | 优先处理 |
| --- | --- | --- |
| 产品事实 | 成分、规格、材质、性能、认证与资料不一致 | 回到资料核实，删去未知内容 |
| 效果与比较 | 保证有效、具体效果数字、第一／唯一、优于竞品、前后对照 | 要求匹配产品及使用条件的证据；不足则改写或移除，不一概断言某个词在所有地区违法 |
| 价格与活动 | 虚构原价、折扣、倒计时、库存、赠品、免费或免运条件 | 确认价格依据、期限与限制条件；未知则不写入发布稿 |
| 评价与背书 | 编造用户体验、专家、奖项、销量；虚构购买者身份 | 移除虚构内容，核实来源、授权及适用披露要求 |
| 敏感品类 | 医疗、保健、化妆品、食品、金融、酒类或其他受监管产品 | 避免未经证实的治疗、减重、收益或安全性保证；按地区及平台进一步核实 |
| 人群与叙事 | 针对未成年人、不当羞辱、歧视、制造健康焦虑或不安全操作 | 修改定向、文案或场景，核实具体限制 |
| 素材权利 | 人脸、名人、商标、配乐、字体、第三方图片或用户评价 | 确认来源与授权；无法确认时换用适当自有或获授权素材 |
| 演绎真实性 | AI 人物充当真实顾客；模拟实验当作证据；夸张演示暗示功能 | 修改误导性表达；按适用规则核实标识／披露要求，披露不能替代证据 |
| 信息一致性 | 文案、画面、CTA 与用户提供的落地页价格或承诺冲突 | 对照已提供内容修正；未提供落地页则明确未检查 |

产品周围的花朵、水果或其他意象不自动证明香料、成分或真实工艺；声音变化也不自动证明产品功效。直接修改可能误导的画面与视听因果，风险初筛保持简短，不挤占创意主体。

## 声音与制作设定的专项检查

- 音效、音乐消失或环境突然静音也会暗示性能，例如无依据的完全降噪、隔音或瞬间净化；检查整条视听因果，不只检查文案。
- 摄影机和镜头名称是影像参考，不声称已实拍、已租赁或保证精确模拟，也不使用不存在的器材型号或虚构兼容性。
- BGM提示词不等于音频已生成或获得商用授权；人物、品牌落版、Logo、字体和第三方道具图案分别确认用途与权利。
- 未指定投放地区和平台时，不用此项阻塞概念创作，但明确未完成适用政策审核；不要作具体法律结论。

## 交付风险结果

只列实际发现的问题；没有足够信息不等于没有风险。建议表格字段：

「位置／原表达 → 风险或证据缺口 → 建议修改 → 仍需确认的依据」。

使用合适的状态：
- 已修订：表述或画面问题已在本稿修改。
- 待证据：仍需产品规格、测试、授权、报价等资料。
- 待地区／平台审核：尚未核实适用政策或法律。

当风险阻碍发布时，明确「概念稿，完成所列核实与审核后再考虑投放」。不要使用“保证合规”“必定过审”“零风险”，也不要把一般性初筛说成法律审核。
