# 用户参考片的视觉语法

来源为用户提供的11个本地案例视频，已通过按约1秒间隔抽帧观察画面顺序；该批参考未逐段核听音轨。这里只保存视觉创意提炼，不推断真实拍摄设备、幕后制作方法、原片BGM或精确逐帧剪辑。使用本skill不依赖原始视频目录存在。

## 已观察的不同创作路线

- **珠宝案例**：暗色建筑、黑豹形象、闪耀粒子和佩戴细节，体现图腾意象到产品设计细节的呼应。
- **都市配饰案例**：街道、咖啡馆、穿行人物、包袋／眼镜细节和花朵，体现生活动作中的产品叙事；另一条通过黑白与彩色、材质特写和照片式收束形成变化。
- **汽车案例**：机械／操作细节、海岸道路、驾驶人物、轮胎、日落远景，体现速度、驾驶体验和生活方式交替；不推断具体性能。
- **复古奇想案例**：高饱和服装、室内花园、花朵／昆虫意象、人物动作与包袋，体现一个统一世界观内的奇观和主色呼应。
- **工艺与几何案例**：手工动作、皮革观感表面、几何物体、自然地貌和包袋细节，体现形态、触感与环境的关联；不能照此认定新产品的真实工艺。
- **人物生活方式案例**：城市出发到牧场、车辆、马匹、穿搭和光线变化；另有旷野服饰群像，体现节制表演、环境尺度与服装细节的交替。
- **Y2K彩妆案例**：唇部微距、银色反射、屏幕／数字图像、霓虹运动和产品收束，体现纹理、时代审美和节奏变化。
- **家庭家电案例**：室内光线、人物休息、宠物、地面运动与草地／花朵意象，体现生活情绪的视觉化。对新产品不可据此暗示未经证实的净化、健康或清洁效果。
- **人物奇想案例**：红色果实、香水观感瓶身、街道人物、漂浮道具和红绿色呼应，体现单个视觉母题贯穿事件。

## 可迁移的方法，而非固定公式

1. 从产品轮廓、细节、可证实用途或气质找到视觉母题。
2. 用环境、人物、动作、细节和产品展示建立有起伏的镜头序列。
3. 生活方式真实动作可以构成整片，不要求每片都超现实。
4. 需要奇观时，集中在一个有产品关联的核心事件，不把粒子、花海、宇宙和液态金属堆在同一条片里。
5. 产品可开场出现、逐渐显露或后段揭晓，按叙事选择；不要把“先氛围后产品”当成一律适用的强制要求。
6. 细节／完整形态／使用状态要为观众提供产品识别，不能让故事或模特完全盖过产品。
7. 结尾有意识地收束：产品停留、情绪完成、文案／品牌留位，不必一律黑底Logo。
8. 原创BGM与剪辑方案应根据当前创意设计，不说自己听过或复刻了这些参考的声音。

不要把参考品牌名当作新产品的风格指令或版权授权；不搬用广告语、肖像、Logo和独特镜头组合。产品与品类不同，应从关联理由重新设计，不只是把原片产品替换掉。
