# Ivorywhite Ad Creative

从产品图策划产品广告视频创意与制作方案的 Codex skill。

它适合：产品白底图广告、短视频广告创意、品牌视觉提案、图生视频分镜、模特／场景资产提示词，以及 BGM 与剪辑设计。

> 这是创意与提示词工作流，不会默认生成、上传、投放或发布成片。

## 核心能力

- **三案创意**：第一轮提出三个有实质区别的广告创意，并推荐一个。
- **多轮探索**：如果三个方案都不喜欢，继续只输出新一轮创意；用户选定后再展开对应方案。
- **A／B交付**：
  - **A版｜导演创意方案**：产品观察、创意、摄影、色调、场景、模特、道具、分镜、BGM、剪辑和执行难点。
  - **B版｜直接使用提示词**：模特图片、场景图片、必要道具图片，以及与 A 版镜号对应的独立视频提示词和 BGM 提示词。
- **短片与长片**：默认 30 秒内；用户指定 45 秒、60 秒或更长时，沿用已选创意扩展故事，并按不超过 30 秒的生成段分段制作。
- **16+ 镜头**：完整方案至少 16 镜，可根据故事节奏增加，不用重复镜头凑数。
- **两种生成路径**：可以只使用产品图直接生成，也可以先准备模特、场景和必要道具资产。

## 调用

显式调用：

```text
$ivorywhite-ad-creative
```

也可以直接上传一张产品图并描述任务，例如：

```text
根据这张产品图写创意广告。
```

默认会进入第一轮完整流程：三个创意、简短推荐，以及推荐方案的 A／B 版。

## 常用请求

### 1. 首轮完整创意

```text
根据这张产品白底图写创意广告。
```

### 2. 只先看创意

```text
先给我三个创意，暂时不要展开分镜。
```

### 3. 选择其他方案

```text
我喜欢方案二，请直接展开方案二的 A／B 版。
```

### 4. 继续换创意

```text
这三个方案我都不喜欢，再来一轮完全不同的创意。
```

skill 会只输出新一轮三个方案，并询问你是否对其中一个感兴趣；不会重复展开上一轮的长篇脚本。

### 5. 延长已选方案

```text
这个创意不错，但30秒太短了，扩展成60秒长片。
```

skill 会沿用已选创意，不重新生成三案，并将新增的内容、分段生成安排、A／B时间线、BGM和剪辑统一扩展到60秒。

## 输出规则

- 默认短片总长不超过 30 秒；片尾落版和声音收尾包含在总时长内。
- 长片采用用户指定总长；每个计划生成段不超过 30 秒，最后通过剪辑合成完整长片。
- 完整方案至少 16 个实质镜头，可以更多。
- A 版、B 版、BGM 和剪辑使用同一条时间线。
- 不提供关键画面、首帧、尾帧或逐镜故事板图片提示词。
- 摄影机和镜头是影像参考，不代表实际拍摄或保证模型精确模拟。
- 产品白底图能证明外观，但不能自动证明功效、规格、认证、参数、评价或商用权利。
- Logo、长文字、人物、音乐、字体和第三方素材正式使用前需要确认授权。

## 仓库结构

- `SKILL.md`：主工作流和交互规则。
- `agents/openai.yaml`：skill 的展示名称、简介和默认调用提示。
- `references/director-treatment.md`：A 版导演方案和长片扩展规范。
- `references/visual-prompts.md`：B 版图片与逐镜视频提示词规范。
- `references/creative-language.md`：参考广告片的视觉语法提炼。
- `references/seedance-adaptation.md`：指定视频工具时的适配规则。
- `references/ad-risk-review.md`：广告风险初筛清单。

## 适用边界

这个 skill 适合创意策划、导演方案和生成提示词，不等于：

- 已生成的视频、图片或音乐文件；
- 已完成的法律审查或平台过审；
- 已验证的产品性能广告；
- 已获得品牌、人物、字体、音乐或第三方素材授权。

## 反馈建议

如果输出出现以下问题，建议在 Issue 中附上产品类别、使用的请求和相关片段：

- 三个创意过于相似；
- A／B 时间线不一致；
- 镜头少于16个或镜头重复凑数；
- 产品外观在镜头间变化；
- 长片没有增加有效故事内容，只是拉慢短片；
- 资产提示词与视频提示词无法配合使用。
